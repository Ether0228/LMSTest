# 学生通关指南 — 设计方案

## 核心设计哲学

**比喻骨架：校园即副本，学期即章节，作业即任务，毕业即通关。**

不做地牢 RPG，做的是**《旅行青蛙》+ Notion 的结合体**——安静、干净、有温度，但每次打开都有新进展可以看。游戏感来自于"进度感"和"仪式感"，而不是视觉特效。

---

## 可用数据盘点

| 数据 | 来源 | 可展示内容 |
|---|---|---|
| 已获/目标学分 | 花名册 | XP 进度条、离毕业还差多少 |
| OSSLT 状态 | 花名册 | 省考闯关状态 |
| 公告字段 | 花名册 | 个人 + 全体通知 |

| 作业库（截止日期、性质） | 作业库 | 智能日历、任务清单 |
| 缺交记录 | 缺交表 | 未完成任务告警 |
| AOL 得分、分类权重 | Gradebook | 学科战绩、Boss 关进度 |
| 课程总分% | Gradebook | 每门课的通关进度 |
| 学期日历 | academic_calendar.json | 8周时间轴、当前位置 |

## 页面结构

### 入口层：身份识别

飞书免登（OAuth），进来直接显示该学生数据，无需任何操作。

---

### 主页：今日战报（Daily Brief）

> 目标：学生每天早上打开，30 秒内知道今天要干什么。

**顶部 Hero 区**

```
  Ziwei Huang  |  Scholar · S4  |  ████████░░  14/18 学分
  "本章还有 3 周，你已完成 67% 的任务"
```

- 左：学生姓名 + 当前学期标签
- 中：学分进度条（XP 感，距毕业还差 N 学分）
- 右：当前周次 / 学期总周数（第 5 周 / 共 8 周）

**今日任务栏**

按紧急程度分三档：

```
🔴 需要立刻处理（缺交 / 截止 < 48h）
🟡 本周任务（截止 < 7 天）
🟢 已完成（今日新提交）
```

**公告区（右侧浮动卡）**

- 全员公告 → 淡色背景
- 个人专属通知 → 高亮边框 + "仅你可见"标签

---

### 模块 A：学期副本地图（Semester Map）

> 解决"学生不知道自己在哪"的问题。

8 周横轴时间线：

```
  入学  W1  W2  W3  W4 [W5←你在这] W6  W7  W8  结业
   ●────●────●────●────◉────────────○────○────○────○
```

- 已过的周：实心，显示该周提交了几份作业
- 当前周：高亮，显示本周 deadlines
- 未来的周：空心，有已知 deadline 的显示标记
- 两学期并行时：两条平行时间线，S3（收尾）在上，S4（新开）在下

---

### 模块 B：课程战场（Course Battles）

每门课一张卡片：

```
┌─────────────────────────────────────┐
│  ICS3U  Grade 11 Computer Science   │
│  总进度  ████████░░  80%            │
│                                     │
│  📋 作业   12/14 完成               │
│  ⚔️  AOL   Quiz1 ✓  Quiz2 ✗  Final ○│
│  📊 当前成绩  83.5%                 │
└─────────────────────────────────────┘
```

- AOL 用 Boss 关卡图标（⚔️）区分，每个显示 ✓ / ✗ / 未开放
- 点进去展开：该课所有作业列表 + 各 AOL 得分明细

---

### 模块 C：学业档案（Profile Stats）

```
  ┌──────────────────────────────────┐
  │  学号     Q2024-0123             │
  │  已获学分  14 / 18               │
  │  OSSLT    ✅ 通过                │
  │  连续提交  🔥 12 天              │
  │  本学期    S4 (2025-2026)        │
  └──────────────────────────────────┘
```

**提交热力图**（GitHub contributions 风格）

```
  Mon  ░░▒▓█░░▒▓█░░▒▓
  Wed  ░▒░░▓█░▒░░▓█░▒
  Fri  ▓█░▒░░▓█░▒░░▓█
       ← 过去 8 周 →
```

颜色深度 = 当天提交作业数，让学生看到自己的学习节律。

---

### 模块 D：OSSLT 闯关状态

通过时：

```
  省考通道
  ─────────────────────────────────
  ✅ OSSLT Reading    通过
  ✅ OSSLT Writing    通过

  状态：省考资格已达成，升学无障碍 🎉
```

未通过时：

```
  ❌ OSSLT Writing   未通过

  建议：每周完成写作练习 → 找 [老师姓名] 约补考
  相关资源：[快速链接]
```

---

### 模块 E：智能日历

月视图 + 周视图切换：

- 🔴 红色：AOL / 大考 deadlines
- 🟠 橙色：普通作业 deadlines
- ✅ 绿色打勾：已提交
- 悬停显示：作业名、课程、是否高分值

---

### 模块 F：求助指引

不做大而全的知识库，只做快速路由：

```
  我遇到了...

  [作业问题]    [成绩疑问]    [选课/学分]
  [OSSLT]      [升学咨询]    [其他]

  → 匹配对应老师 + 联系方式
```

## 全生命周期设计

| 阶段 | 触发条件 | UI 重点变化 |
|---|---|---|
| **新生入学** | 首次登录，学分=0 | 显示欢迎引导、介绍各模块 |
| **学期中** | 正常状态 | 完整仪表盘，任务驱动 |
| **学期末冲刺** | 剩余 ≤ 2 周 | 时间线高亮倒计时，缺交告警置顶 |
| **两学期切换** | 宽限期内 | 双学期并行视图，S3 显示"收尾模式" |
| **毕业冲刺** | 学分接近目标 | 增加"升学检查清单"（OSSLT + 学分 + 成绩） |
| **通关** | 学分达标 + OSSLT 通过 | 庆祝动画 + 档案留存 |

---

## 吸引学生主动打开的机制

1. **飞书推送入口**：Deadline 前 48h、成绩更新、新公告时推送卡片消息，点击直达对应模块
2. **"今天有新动态"**：每次打开显示自上次登录以来的变化（新提交、公告、成绩更新）
3. **连续提交 Streak**：🔥 连续打卡天数，断了有温和提示
4. **学期通关进度**：进度条从 80% 涨到 100% 有满足感，是持续回访的内在动力
5. **个人通知高亮**：老师单独发给某学生的公告，打开即可见，比群消息更有存在感

## 技术适配

| 项目 | 方案 |
|---|---|
| 认证 | 飞书 OAuth 免登（现有 server.js 基础） |
| 数据主路径 | PostgreSQL（现有） |
| 数据备份 | 飞书汇总表（现有） |
| 前端 | 在现有 `interactive_web/` 扩展，无构建步骤 |
| 新增配置 | 老师-负责模块映射（一张飞书配置表手动维护） |
